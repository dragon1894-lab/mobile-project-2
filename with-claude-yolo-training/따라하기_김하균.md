## 6. 박스 그리기 1차 — 20~30장 (30분~1시간)
Claude가 **학습 툴 창**을 띄워 줘요.

1. [ ] 창에서 **프로젝트 열기** → `바탕화면\crack_iphone` 선택
   - 왼쪽에 사진 목록이 보이고, 오른쪽 클래스 목록에 `crack_iphone`, `crack`이 있으면 OK
   - **사진 가져오기는 안 눌러도 돼요** (Claude가 미리 넣어 둠)
2. [ ] 서로 다르게 생긴 사진 **20~30장**에 박스 2종류 그리기

   | 오른쪽에서 고를 이름 | 그릴 곳 |
   |---|---|
   | `crack_iphone` | **휴대폰 뒷면 전체** (휴대폰 외곽에 딱 맞게) |
   | `crack` | **깨진 부위** (여러 군데면 박스 여러 개) |

3. [ ] 한 장 끝날 때마다 **`Ctrl+S`** (라벨 저장) → **다음 ▶**
4. 잘못 그렸으면 그 박스를 클릭 → **선택 박스 삭제**
5. [ ] 다 했으면 Claude가 부탁할 때 **학습 데이터 만들기** 버튼 누르기
6. [ ] Claude에게 "다 했어"라고 말하기 (창은 닫지 않아도 돼요)
