# 2번 - 사용자(작업자) C# WinForms (장서진)

왼쪽 메뉴로 화면을 바꿉니다.

| 메뉴 | 내용 |
|---|---|
| 01 실시간 검사 | 카메라 연결, 정상 기준 등록, 검사 시작·중지 |
| 02 검사 현황 · 이력 | 라인 누적 개수, 지난 검사 기록 |
| 03 문제 · 조치 | 문제 등록, 확인 → 조치 중 → 완료 요청, 조치 내용 기록 |
| 04 AI 상담 | 문제를 골라 질문. 외부 AI 또는 매뉴얼 답변. **대화는 저장하지 않아 앱을 닫으면 사라짐** |
| 05 관리자 상담 | 문제별 1:1 문의 (5초마다 새 답변 확인, 종결된 문제는 읽기만) |
| 06 단체 채팅 | 관리자·모든 작업자 대화방, 안 읽은 수를 메뉴에 표시 (김하균 추가) |

- AI 상담은 외부 AI 응답이 최대 30초 걸릴 수 있어 이 요청만 35초까지 기다립니다(`AiConsultationApi.cs`).
- 화면 배율이 큰 PC에서도 글자가 잘리지 않도록 csproj에 `ApplicationHighDpiMode=DpiUnawareGdiScaled` (김하균 추가, 10-20).
- 서버 연결 안내는 같은 폴더의 `서버연결_2026-10-19_적용결과.md`, `DB_연동안내.md`를 보세요.
