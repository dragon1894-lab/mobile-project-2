# 생산라인 검사·AI 문제대응 시스템 - C# 기본 베이스

5명이 기능을 나눠 개발하기 전에 함께 실행할 수 있는 기본 솔루션입니다. 모든 프로그램은 C#/.NET 8로 구성하고, 관리자·사용자 PC와 서버는 유선 이더넷 TCP/IP의 HTTP REST/JSON으로 통신합니다.

## 폴더와 담당자

| 폴더 | 담당 | 확장할 기능 |
|---|---|---|
| `00_Shared` | 3번 관리, 전원 합의 | API 요청/응답 DTO와 공용 API 클라이언트 |
| `01_AdminApp` | 1번 | 관리자 로그인, 대시보드, 사용자 관리, 종결, 이력·통계 |
| `02_UserApp` | 2번 | 사용자 로그인, 카메라/검사 화면, 문제 조치, AI 상담 UI |
| `03_Server` | 3번 | 이더넷 REST API, 인증·권한, 저장소, 통합 |
| `04_Vision` | 4번 | 카메라, 형태·윤곽, 색상 검사, 3가지 결과 |
| `05_AiAssistant` | 5번 | 매뉴얼 검색, 상담 답변, 근거, 관리자 전환 |

## 현재 동작하는 기본 흐름

1. 관리자/사용자 로그인 및 역할·라인 권한 검사
2. 관리자 다중 라인 현황 조회
3. 사용자 대표 라인 조회
4. 정상·형태 불량·색상 불량·판정 불가 검사 시뮬레이션
5. 라인 문제 등록과 조치 중·완료 요청·관리자 종결
6. 로컬 매뉴얼 검색 기반 상담 AI와 근거 표시
7. 서버 JSON 저장소에 사용자·검사·문제 이력 보존

## 실행 순서

Visual Studio에서 `ProductionLineSystem.sln`을 열거나 PowerShell 세 개를 사용합니다.

```powershell
.\scripts\build.ps1
.\scripts\run-server.ps1
.\scripts\run-admin.ps1
.\scripts\run-user.ps1
```

초기 계정:

- 관리자: `admin` / `admin123!`
- 사용자: `worker1` / `worker123!`

## 다른 PC에서 이더넷 연결

서버 PC에서 `ipconfig`로 유선 LAN IPv4를 확인합니다. 서버 주소가 `192.168.0.10`이면 관리자·사용자 PC에서 실행 전에 설정합니다.

```powershell
$env:PRODUCTIONLINE_SERVER_URL='http://192.168.0.10:5050'
```

서버는 기본적으로 `0.0.0.0:5050`을 사용합니다. 서버 PC의 방화벽에서 TCP 5050 인바운드 규칙이 필요할 수 있습니다.

## 개발 원칙

- 각 담당자는 자기 번호 폴더를 중심으로 수정합니다.
- `00_Shared` DTO를 바꾸기 전에는 3번 통합 담당자와 전원이 합의합니다.
- DB는 관리자/사용자 앱에서 직접 접근하지 않고 서버 API만 사용합니다.
- 검사 판정은 `04_Vision`, 문제 해결 상담은 `05_AiAssistant`가 담당합니다.
- `main`에는 빌드되는 코드만 병합하고 매일 한 번 통합합니다.

자세한 API와 병합 규칙은 `docs` 폴더를 확인하세요.
