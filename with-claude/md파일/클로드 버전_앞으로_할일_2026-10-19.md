## 4. 마지막: 전체 연결 시험 (앱이 완성되면)

- [ ] 서버 PC 1대 + 관리자 PC + 작업자 PC (서버를 관리자 PC에서 같이 켜면 2대)
- [ ] 두 앱이 같은 서버에 접속해서 **같은 데이터**를 보는지
- [ ] 관리자 로그인 → 작업자 등록 → 작업자 로그인 (전각·중복 아이디는 팝업으로 막히는지)
- [ ] 검사(정상·불량·판정 불가) → 문제 등록 → 확인 → 조치 중 → 완료 요청 → 관리자 반려·종결
- [ ] 작업자 문의 ↔ 관리자 답변이 5초 안에 서로 보이는지
- [ ] 단체 채팅: 서로 보이는지, 새 아이디가 바로 들어오는지, 안 읽은 수가 뜨는지
- [ ] AI 상담: 키를 넣고 실제 AI 답이 오는지, 키를 빼면 매뉴얼 답이 오는지
- [ ] 랜선을 잠깐 뽑았다 꽂아도 다시 연결되는지
- [ ] 통신 기록에 위 과정이 남았는지

> 한 PC 안에서는 10-20에 김하균이 노트북용으로 위 흐름(검사·센서·두 PC 제외)을 직접 해 보고 DB까지 확인했습니다.
