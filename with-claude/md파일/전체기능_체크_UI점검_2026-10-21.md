# 전체 기능 체크 + UI 점검표 (2026-10-21, 김하균)

앱을 직접 써 보면서 **① 기능이 되는지** 확인하고, **② 보기 불편한 화면(UI)**을 그 자리에서 적는 표입니다.
위에서부터 순서대로 하세요. 기준 폴더는 **`with claude\노트북용`**입니다(화면 배율·아이디 팝업·채팅 한글 저장이 들어간 버전).

- ✅ 칸: 정상이면 체크
- **UI 메모** 칸: 글자 잘림, 버튼 위치가 헷갈림, 글씨가 작음, 색이 안 보임, 안내 문구가 어려움 등 고치고 싶은 점
- 기능이 안 되면 **몇 단계 몇 번인지 + 화면 캡처**를 Claude에게 보내기

---

## 0단계. 준비
1. Visual Studio에서 `with claude\노트북용\ProductionLineSystem.sln` 열기
2. 솔루션 탐색기 맨 위 **솔루션** 오른쪽 클릭 → **시작 프로젝트 구성** → **여러 시작 프로젝트**
   - `ProductionLine.Server`, `ProductionLine.AdminApp`, `ProductionLine.UserApp` → **시작**
   - **↑ 버튼으로 Server를 맨 위로** → 확인
3. **F5** (브라우저가 같이 열리면 닫아도 됨)

| # | 확인 | ✅ | UI 메모 |
|---|---|---|---|
| 0-1 | 검은 서버 창과 **서버 연결 창** 2개(관리자·작업자)가 뜸 | ☐ | |
| 0-2 | 관리자 **서버 열기** 창: 이 PC 주소(예: 192.168.x.x:5050) 확인 → **[서버 켜고 접속]** → 관리자 로그인 창 (서버가 이미 켜져 있으면 그 서버에 바로 접속) | ☐ | |
| 0-3 | 작업자 서버 연결 창: 목록의 서버 고르고 [접속] → 작업자 로그인 창 | ☐ | |
| 0-4 | (두 PC로 할 때) 서버 PC는 관리자 앱만 켜고 **[서버 켜고 접속]**, 다른 PC는 작업자 앱 → 목록의 서버 [접속] (못 찾으면 서버 PC 주소 직접 입력) | ☐ | |

> 서버 연결 창은 10-21에 추가됐어요(노트북용). 관리자 앱은 '서버 열기'만 있어요(서버가 이미 켜져 있으면 그 서버에 접속). 작업자 앱은 '서버 접속'만 있어요.

> 코드를 고친 뒤 다시 빌드할 때는 **Shift+F5로 모두 끄고** 빌드하세요. 켜져 있으면 "파일이 잠겨 있습니다" 오류가 납니다.

## 2단계. 단체 채팅
1. 작업자 앱 왼쪽 **06 단체 채팅** → "안녕하세요" 입력 → **Enter**
2. 관리자 앱 위쪽 **단체 채팅** 버튼 → 작업자 메시지 확인 → "확인했어요" 보내기
3. 관리자 채팅 창을 **X로 닫기**
4. 작업자가 "하나 더" 보내기
5. 작업자 앱에서 다른 메뉴(예: 01)로 간 뒤, 관리자가 하나 더 보내기

| # | 확인 | ✅ | UI 메모 |
|---|---|---|---|
| 2-1 | 메시지가 2~3초 안에 서로 보임 | ☐ | |
| 2-2 | 보낸 사람 이름·역할·시각이 보기 쉬움 | ☐ | |
| 2-3 | 관리자 창을 닫아 둔 상태에서 버튼이 **"단체 채팅 (1)"**로 바뀜 | ☐ | |
| 2-4 | 창을 다시 열면 (1)이 사라짐 | ☐ | |
| 2-5 | 작업자 메뉴가 **"06 단체 채팅 (1)"**로 바뀌고, 열면 사라짐 | ☐ | |
| 2-6 | Shift+Enter로 줄바꿈 됨 | ☐ | |

## 3단계. 문제 처리 (상태 순서)
1. 작업자 앱 **03 문제 · 조치** → 새 문제 등록 (예: 제목 "벨트 멈춤")
2. **확인 → 조치 중** → 조치 내용 "벨트 점검함" 저장 → **완료 요청**
3. 관리자 앱 **완료 요청 확인**
   - 사유 없이 **반려** → 안내가 떠야 정상
   - 사유 "사진 첨부 필요" 넣고 **반려**
4. 작업자 앱에서 그 문제가 **조치 중**으로 돌아오고 반려 사유가 보이는지 확인 → 다시 **완료 요청**
5. (4단계 1:1 문의를 먼저 한 뒤) 관리자가 **종결**

| # | 확인 | ✅ | UI 메모 |
|---|---|---|---|
| 3-1 | 문제 등록이 되고 목록에 나타남 | ☐ | |
| 3-2 | 지금 상태에서 누를 수 있는 버튼만 켜져 있음 (순서 건너뛰기 불가) | ☐ | |
| 3-3 | 작업자 앱에는 **종결 버튼이 없음** | ☐ | |
| 3-4 | 관리자는 **완료 요청** 상태에서만 종결·반려 가능 | ☐ | |
| 3-5 | 사유 없이 반려하면 안내가 뜸 | ☐ | |
| 3-6 | 반려 사유가 작업자 화면에서 잘 보임 | ☐ | |
| 3-7 | 상태 이름(발생·확인·조치 중·완료 요청·종결)이 한글로 알아보기 쉬움 | ☐ | |

## 6단계. 사용자 추가·비활성화
1. 관리자 앱 **사용자 관리** → 아이디 `test1`, 이름, 비밀번호 `test123!`, 1번 라인 → **사용자 추가**
2. 같은 아이디(`test1`, `TEST1`)로 또 추가
3. 한글·전각·띄어쓰기 아이디로 추가 (예: `홍길동`, `ｔｅｓｔ２`, `te st`)
4. 작업자 앱 **로그아웃** → `test1` 로그인 → **06 단체 채팅** 열기
5. 관리자가 `test1` **비활성화** → 작업자 앱에서 아무거나 누르기 (예: 새로고침)

## 9단계. DB 확인 (DB Browser for SQLite)
1. **Shift+F5로 서버를 먼저 끄기** (켜져 있으면 파일이 잠길 수 있음)
2. DB Browser → **데이터베이스 열기** →
   `with claude\노트북용\03_Server\ProductionLine.Server\App_Data\productionline.db`
3. 위쪽 **데이터 탐색** 탭 → **테이블** 드롭다운을 바꿔 가며 보기
4. **보기만 하고 칸을 고치거나 "변경사항 저장하기"를 누르지 않기.** 다 보면 **데이터베이스 닫기**

| # | 테이블 | 정상이면 보이는 것 | ✅ |
|---|---|---|---|
| 9-1 | **Users** | admin(Role 0), worker1(Role 1), 새로 만든 계정. PasswordHash는 알아볼 수 없는 글자(비밀번호 원문 없음). 비활성화한 계정은 IsActive **0** | ☐ |
| 9-2 | **UserLineAccesses** | 아이디마다 볼 수 있는 라인 번호 (예: `worker1 · 1`, `test1 · 1`) | ☐ |
| 9-3 | **Lines** | 라인 1~4. IsReal은 1번만 1(실제), 나머지 0(가상) | ☐ |
| 9-4 | **Issues** | 3단계 문제. Status 4 = 종결, ActionNote에 조치 메모. 처리 안 한 문제는 ActionNote가 비어 있음(NULL) | ☐ |
| 9-5 | **IssueHistories** | 상태 변화가 한 줄씩: 0→1→2→3→**2(반려, 사유)**→3→4. ChangedBy에 바꾼 사람(worker1, admin) | ☐ |
| 9-6 | **IssueMessages** | 4단계 "도와주세요", "지금 갈게요". SenderRole 0 관리자, 1 작업자 | ☐ |
| 9-7 | **RequestLogs** | 통신 기록. Action에 "로그인", "메시지 보내기" 등. **비밀번호·메시지 내용은 없어야** 정상. 7일 지나면 CSV로 백업 후 삭제 | ☐ |
| 9-8 | **Inspections** | 검사를 했으면 기록, 안 했으면 비어 있어도 정상 | ☐ |

**DB에 없어야 정상인 것**
- **단체 채팅** → DB가 아니라 파일: `노트북용\03_Server\ProductionLine.Server\Data\group-chat.json`
  메모장으로 열면 보낸 사람·시각(한국 시간)·내용이 한글로 보임 ☐
- **AI 대화** → 어디에도 저장 안 함 ☐

참고: 시각 칸 일부가 큰 숫자로 보이는 건 정렬용으로 숫자로 저장한 것이라 정상입니다.
