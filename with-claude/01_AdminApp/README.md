# 1번 - 관리자 C# WinForms (조영준)

- 관리자 로그인, 서버 연결 상태 표시
- 라인 현황 카드(5초 자동 갱신), 상세 보기
- 사용자 추가·수정·비활성화
  - 추가할 때 아이디 규칙(영어·숫자·`_`·`-` 3~20자) 위반이나 중복(대소문자 무시)이면 **팝업**으로 알리고 입력을 지우지 않음 (김하균 추가, 10-20)
- 완료 요청 확인 → 종결 / 반려(사유 필수)
- 검사 결과·문제 조회, 검사 이력·통계
- 1:1 문의 답변 (문제별, 종결된 문제는 읽기만)
- 단체 채팅 버튼 (창을 닫아도 계속 받고, 안 읽은 수 표시) (김하균 추가)
- 화면 배율이 큰 PC에서도 글자가 잘리지 않도록 csproj에 `ApplicationHighDpiMode=DpiUnawareGdiScaled` (김하균 추가, 10-20)
