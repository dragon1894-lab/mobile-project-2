# 1번 - 관리자 C# WinForms

통합된 기능:

- 관리자 전용 로그인
- 여러 라인 대시보드
- 사용자 조회·검색·추가·이름/비밀번호/허용 라인 수정·계정 비활성화
- 대표 라인 상세, 검사 결과/문제 조회, 날짜/라인/판정별 검사 이력과 통계
- 완료 요청 검토 후 종결 또는 반려, 조치 메모 보존
- 대시보드·대표 라인 상세 5초 자동 갱신

`ProductionLineSystem.sln`의 `ProductionLine.AdminApp`을 실행합니다. 관리자 화면은 실제 서버 API 모드이며, 서버를 먼저 실행해야 합니다. 초기 계정은 `admin / admin123!`입니다. 압축파일에 있던 임시 계정 `a / a1`은 실제 서버 로그인에 사용하지 않습니다.

사용자 계정을 수정하면 해당 사용자의 기존 로그인 세션은 만료됩니다. 사용자 앱에서 변경된 계정으로 다시 로그인해야 합니다. 통계는 서버가 반환한 최근 검사 기록(라인별 최대 100건)으로 계산하며 화면에도 조회 범위를 표시합니다.

원본 압축파일의 PC 종속 프로젝트 경로 대신 공용 `00_Shared` 프로젝트를 참조합니다. 기존 소스 백업은 `output/backups/before-admin-ai-integration-*.zip`에 있습니다.
