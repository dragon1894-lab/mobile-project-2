# 아이폰 기종 YOLO 데이터 감사 결과 (2026-10-19)

아래는 전체 외곽 재학습 적용 **전** 감사 기록이다. 이후 원본 7장을 전체 박스로 수정해 `phone` 위치·크기 모델을 학습·적용했다. 현재 상태는 [최신 적용 안내](PHONE_FULL_BODY_TRAINING_20261019.md)를 참고한다. 색상과 여섯 기종 분류의 자료 부족은 아직 해결되지 않았다.

## 결론

현재 배포 모델은 여섯 기종을 판별할 수 있는 상태가 아니다. 배포 모델의 클래스는 6개지만 실제 제공 학습 자료는 4장이고, 실제 라벨이 존재하는 기종 클래스는 `iphone_16`과 `iphone_15_pro`뿐이다. 최상위 통합 데이터셋도 총 7장(학습 6, 검증 1)에 불과하다.

검증 이미지가 1장이므로 결과 CSV의 mAP50 0.995는 일반화 성능의 근거로 사용할 수 없다.

## 확인된 품질 문제

- 모든 사진이 같은 컨베이어, 거의 같은 거리와 조명에서 촬영됐다.
- 일부 라벨은 휴대폰 전체, 일부 라벨은 후면 카메라 모듈만 표시해 라벨 기준이 일치하지 않는다.
- 검증 세트가 1장이며 동일 촬영 세션의 유사 프레임이라 데이터 누수가 발생할 가능성이 높다.
- 12 Pro와 12 Pro Max는 외관 특징이 매우 비슷하므로 픽셀 크기만으로 구분하면 카메라 높이 변화에 취약하다. 고정 카메라·고정 거리 조건을 유지하고, 실제 크기를 구분할 수 있는 기준 물체 또는 캘리브레이션이 필요하다.
- 인터넷 상품 사진만 추가하면 실제 컨베이어 배경과 조명에 대한 도메인 차이가 커진다.

## 권장 조치

새 프로젝트 `training/iphone_models_v2`에서 요청한 여섯 기종을 동일한 전체 박스 기준으로 다시 라벨링한다. 각 기종은 최소 350개의 서로 다른 실제 프레임을 확보하고, 촬영 세션 단위로 학습 250·검증 50·테스트 50을 분리한다. 빈 벨트와 비대상 휴대폰도 별도로 포함한다.

기존 모델과 새 모델의 가중치 파일을 합치지 않는다. 원본 데이터셋을 합쳐 사전학습 체크포인트에서 단일 모델을 재학습하고, 별도 테스트 세트 및 실제 컨베이어에서 검증한 뒤 ONNX로 내보낸다.
