컨베이어 PC(Intel 내장그래픽, GPU 없음)의 `04_Vision/models`와 `training/`에 있던 옛 모델을 **2026-10-21 v2로 바꾸면서 보관**한 폴더입니다. 학습 모델 파일(`.onnx`, `.pt`)과 모델 설명 json만 있고 사진·라벨·그래프는 뺐습니다. 폴더 이름은 원래 이름 그대로입니다.

- **지금 앱이 쓰는 모델은 `training_model/v2`** (= `all_phones/models/best.onnx`) 하나뿐입니다. 여기 모델은 앱에 다시 넣지 마세요.

## 왜 모두 사용 중지했나

1. **모델마다 3번 클래스 하나만 학습** — 기종별로 따로 학습해서 0~2번(`target_iphone`, `other_phone`, `crack`)은 사진 0장, 3번만 자기 기종입니다. “이 기종이 아니다”를 배운 적이 없어서 **어떤 폰이든 자기 기종이라고 답합니다**(교차 시험에서 07·09·10·11은 다른 기종 사진을 100% 자기 기종으로 판정).
2. **파손 모델은 정상 폰 사진 없이 학습** — 최상위 모델(`crack_phone`)과 12번(`iphone_12_pro_max_Crack`)이 정상 폰도 파손으로 검출. 앱이 이 14개를 동시에 돌린 결과 **컨베이어 정상 폰 8장이 모두 불량**, 1장 판정 약 960ms.
3. v2(통합 5클래스, 1장 약 70ms)는 같은 사진 8장에서 정상→불량 0장. 자세한 비교: `all_phones/README.md`, `all_phones/from_local_pc_20261020/HANDOFF.md`.
