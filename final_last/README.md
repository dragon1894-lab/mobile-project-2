2. 관리자 다중 라인 현황 조회
3. 사용자 대표 라인 조회

6. 문제·조치 화면 안의 **관리자 채팅**(문제별 1:1, 문제가 조치 중일 때만 전송). 별도 1:1 메뉴는 없음
7. 활성 계정 전원이 참여하는 **단체 채팅**
8. AI 상담: 문제를 고르지 않아도 바로 질문(자유 상담), AI 미설정/실패 시 기본 매뉴얼 답변. 화면 위쪽 상태 영역에 서버·AI 연결, 응답 결과·응답 시간, [연결 확인]·[장비 상태 확인] 버튼
9. 관리자 앱: 라인 1의 실제 벨트·가속·긴급정지·서보 상태 표시, 원격 조작, **전체 정지**(작업자 정지 응답 확인)
10. 서버 SQLite DB(`App_Data/productionline.db`)에 계정·검사·문제·이력·관리자 채팅 저장. 단체 채팅은 `data/group-chat.json`, 검사 사진은 `data/inspection-images`
11. 아이폰·다른 휴대폰·표면 깨짐 사진의 YOLO 라벨링 및 모델 학습
12. Arduino Mega PUL/DIR 제어, C# 업로드 화면, **인식돼도 계속 이동하는 연속 검출**. 작업자 앱에서 COM 선택·벨트 연결·벨트 구동 — [제어 안내](hardware/README.md)

## 실행 순서

Visual Studio에서 `ProductionLineSystem.sln`을 열거나 PowerShell 세 개를 사용합니다.

```powershell
.\scripts\build.ps1
.\scripts\run-server.ps1
.\scripts\run-admin.ps1
.\scripts\run-user.ps1
```

초기 계정:

- 관리자: `admin` / `admin123!`
- 사용자: `worker1` / `worker123!`

2026-10-17 관리자 화면과 AI 상담 수정본을 이 솔루션에 통합했습니다. 관리자 앱은 실제 서버 데이터로 사용자 관리·대표 라인 상세·검사 이력/통계·완료 요청 종결/반려를 처리합니다. 외부 AI 키는 서버에서 설정하며, 없어도 기본 매뉴얼 상담을 이용할 수 있습니다. [통합 실행 안내](docs/ADMIN_AI_INTEGRATION.md)를 참고하세요.

## 다른 PC에서 연결

- 관리자 앱을 실행하면 연결 창에서 **[서버 켜고 접속]**으로 이 PC에 서버를 켜고 접속 주소(`http://<IPv4>:5050`)를 보여 줍니다.
- 작업자 앱의 연결 창은 같은 네트워크의 서버를 **자동으로 찾습니다**(UDP 5051). 목록에 없으면 서버 PC의 IP를 직접 입력합니다.
- 서버는 한 대만 켜세요. 두 대가 각각 켜면 데이터가 따로 저장됩니다.
- 서버는 `0.0.0.0:5050`을 사용합니다. 다른 PC에서 못 찾으면 서버 PC 방화벽에서 TCP 5050·UDP 5051 인바운드를 허용합니다.
- 압축은 `C:\PL\ProductionLine_final`처럼 **짧은 경로**에 푸세요. 경로가 길면 서버가 `e_sqlite3` DLL 오류로 꺼집니다.
- 환경 변수 `PRODUCTIONLINE_SERVER_URL`로 서버 주소를 미리 지정할 수도 있습니다.

## 개발 원칙

- 각 담당자는 자기 번호 폴더를 중심으로 수정합니다.
- `00_Shared` DTO를 바꾸기 전에는 3번 통합 담당자와 전원이 합의합니다.
- DB는 관리자/사용자 앱에서 직접 접근하지 않고 서버 API만 사용합니다.
- 검사 판정은 `04_Vision`, 문제 해결 상담은 `05_AiAssistant`가 담당합니다.
- `main`에는 빌드되는 코드만 병합하고 매일 한 번 통합합니다.

자세한 API와 병합 규칙은 `docs` 폴더를 확인하세요.
